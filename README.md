# 🛒 E-Commerce Full Stack App (Spring Boot + Angular)

A full-featured E-Commerce web application built using **Spring Boot** for the backend and **Angular** for the frontend. This project demonstrates a modern full stack architecture with OKTA authentication, and a responsive UI.


Objective – A full-stack e-commerce web application with secure authentication and 
payment integration. The system enables users to register/login via third-party 
providers and perform transactions securely.
